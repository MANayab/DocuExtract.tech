## Architecture

The website is static HTML and CSS. It does not require a frontend build step or runtime JavaScript. Pages use relative internal links so they can work under the configured GitHub Pages project path and a correctly configured custom domain.

The site uses a shared stylesheet at `assets/styles.css`. The favicon and social preview are referenced at `assets/logo.svg` and `assets/social-preview.png`. Supply those original assets in the repository; they are not generated by the website.

The product's invoice-processing implementation is a separate application. This marketing site must not imply that the application processes scanned PDFs or multiple invoices per PDF in the current release.

## Product facts

DocuExtract converts supported text-based invoice PDFs into XLSX, CSV and JSON in the browser.

- XLSX and JSON contain the full invoice.
- CSV contains line items only.
- Multi-page text-based PDFs are supported up to 100 pages.
- Extraction is heuristic, and results must be reviewed before accounting, tax, payment or legal use.
- Scanned and image-only PDFs are not currently supported.
- One invoice per PDF is supported.

See the [processing guide](https://manayab.github.io/DocuExtract.tech/how-it-works/) and [FAQ](https://manayab.github.io/DocuExtract.tech/faq/) for details.
