DocuExtract roadmap

This roadmap separates capabilities documented in the source from future ideas. Planned work is not committed, and no delivery dates have been announced.

Released: documented in source version 1.3.1

The software source declares version 1.3.1 in its canonical SITE configuration. The deployed app version and formal GitHub release status were NOT VERIFIED during this update.

  • Batch processing for up to 50 PDFs, with per-file progress, statuses and possible-duplicate detection.
  • File limits documented by the app UI: 25 MB and 100 pages per PDF.
  • Multi-invoice splitting when invoice numbers change; multi-page invoices are kept together, but boundary edge cases are not fully tested.
  • GST-aware fields: GSTIN, HSN, taxable value, tax rate, tax amount and CGST, SGST and IGST.
  • Locale-aware date and number parsing for en-IN, en-US, en-GB and de-DE, with ambiguous-date warnings and reprocessing that protects manual edits.
  • Combined XLSX workbook, invoice-level CSV, line-item CSV and JSON with validation status.
  • Heuristic extraction, validation and a review workflow. Review all values before accounting, tax, payment or legal use.

Optional, build-dependent: local OCR

Source documentation describes optional Tesseract OCR served from the same site when the build bundles the required assets. It supports English only, up to 20 pages per PDF, caps OCR confidence at 75% and marks OCR results for review. Poor scans, handwriting and skewed pages may produce weak results.

NOT VERIFIED: whether the currently deployed app includes and successfully serves the OCR assets. Do not assume OCR is enabled in every build.

Planned work

The following items are planned only. There are no delivery dates or promises.

  • Additional OCR languages (not released; English is the only documented OCR language).
  • Consent-based vendor templates.
  • Offline-capable progressive web app (PWA).

How are roadmap changes communicated?

The public source repository and issue tracker are the appropriate places to inspect current code and follow project discussions. A planned item on this page is not a promise that it has been implemented, tested, or released.
