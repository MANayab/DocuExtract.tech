DocuExtract roadmap

This roadmap distinguishes capabilities documented for v1.0.0 from ideas planned for Phase 2. Planned work is not committed, and no delivery dates have been announced.

Released: DocuExtract v1.0.0

The current release converts supported text-based invoice PDFs into structured XLSX, CSV and JSON in the browser. The workflow includes a review screen so people can inspect the extracted data before exporting it.

  • Browser-based invoice PDF processing without an application backend or account.
  • Text-based PDF support, including multi-page documents up to 100 pages.
  • Export to XLSX and JSON for full invoice data, and CSV for line items only.
  • Review screen before export.
  • Date-confirmation flags for numeric dates.
  • Zod validation of structured data.
  • Formula-injection sanitization on exports.
  • Privacy design that avoids writing invoice data to URLs, localStorage or sessionStorage.

Planned: OCR for scanned and image-only PDFs

OCR means optical character recognition, a process that reads text from document images. OCR support for scanned and image-only PDFs is planned for Phase 2, but it is not currently available and is not committed to a delivery date.

For the current release, select a text-based PDF. Do not assume a scanned page will be interpreted simply because it is contained in a PDF file.

Planned: multiple invoices per PDF

Support for multiple invoices inside one PDF is planned for Phase 2. It is not currently supported and has no committed delivery date.

For the current workflow, separate invoices into individual PDF files and process one invoice per PDF.

How are roadmap changes communicated?

The public source repository and issue tracker are the appropriate places to inspect current code and follow project discussions. A planned item on this page is not a promise that it has been implemented, tested, or released.
