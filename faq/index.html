CLEAR ANSWERS

DocuExtract frequently asked questions

Find practical answers about private invoice conversion, file compatibility, export formats, extraction accuracy, licensing and how to get started.

Privacy and security

Are my invoice PDFs uploaded to a server?

Application code processes invoice files locally in your browser and does not upload them to an application backend. You can inspect your browser's network tab to verify the network activity observed while using the app.

Does DocuExtract use accounts, analytics or storage?

DocuExtract has no application account, backend, database, analytics or telemetry. Invoice data is never written to URLs, localStorage or sessionStorage. PDF buffers are released and documents are destroyed after processing.

Formats and exports

Which export formats are available?

DocuExtract exports XLSX, CSV and JSON. XLSX is a combined workbook; CSV supports invoice-level and line-item exports; JSON includes validation status. Review the extracted information before choosing an export format for your workflow.

Does CSV contain the full invoice?

CSV has two scopes: invoice-level rows or line-item rows. XLSX combines invoice-level data with line items, parties, taxes, validation and metadata; JSON includes validation status.

Accuracy and extraction

How accurate is the extraction?

Extraction is heuristic, so correctness depends on the document layout and content. Every output must be reviewed before accounting, tax, payment or legal use. Compare important values with the original invoice rather than relying on an unverified result.

How are numeric dates interpreted?

The locale selector supports en-IN, en-US, en-GB and de-DE. Ambiguous numeric dates are flagged; reprocessing with another locale protects manual edits. Verify every date against the original.

Can DocuExtract extract line items from unusual tables?

Line items are detected from column gaps and the table header. Unusual table layouts may need manual correction on the review screen, so compare quantities, descriptions and amounts with the source document.

Batch processing, GST and locales

How many PDFs can I process at once?

Up to 50 PDFs can be queued. The app shows per-file progress, processing statuses and possible-duplicate warnings. Each file is limited to 25 MB and 100 pages.

Which GST fields are supported?

Supported fields include GSTIN, HSN, taxable value, tax rate, tax amount and CGST, SGST and IGST. Extraction is heuristic; check all tax values against the source invoice.

Which locales are available?

Choose en-IN, en-US, en-GB or de-DE for date and number parsing. Ambiguous dates are flagged, and locale reprocessing protects manual edits.

Limits and compatibility

Are scanned and image-only PDFs supported?

OCR is optional and build-dependent. When bundled, local Tesseract supports English only up to 20 pages per PDF; OCR values are capped at 75% confidence and always marked Review. The deployed build's OCR assets are NOT VERIFIED.

How many pages can a PDF contain?

DocuExtract supports multi-page text-based PDFs up to 100 pages. Keep the document within that stated limit and review the extracted information from the full invoice.

Can I process several invoices in one PDF?

A PDF is split when the invoice number changes, and multi-page invoices are kept together. Invoice-boundary edge cases are not fully verified, so inspect each split and review all results.

What happens with password-protected or corrupt PDFs?

Encrypted files are rejected unless already decrypted, and corrupt PDFs are not supported. Use a valid, readable PDF that you are authorized to process.

Does DocuExtract guarantee handwritten invoice recognition?

No. Handwritten invoice recognition is not guaranteed. Check handwritten values manually against the source and do not use unverified extracted values for consequential decisions.

Licensing and status

What is the current DocuExtract licence?

The software repository's LICENSE and TERMS.md state that DocuExtract is provided under the MIT License and without warranties. No future licensing change is asserted here.

Getting started

How do I get started?

Open the app and drop up to 50 PDFs (25 MB and 100 pages per file). Review extracted fields, tax values, invoice boundaries and warnings, then export a combined XLSX workbook, invoice-level or line-item CSV, or JSON.
