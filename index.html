BROWSER-BASED DOCUMENT EXTRACTION

Invoice PDF to Excel, without sending your invoices away.

DocuExtract is a free, open-source web tool that converts invoice PDFs to Excel (XLSX), CSV and JSON entirely in your browser. It extracts structured invoice data, gives you a review screen before export, and processes files without an application backend, account, database, analytics or telemetry.

THE WORKFLOW

How does DocuExtract work?

DocuExtract processes batches of PDFs locally, extracts text, optionally runs local English OCR when the build includes it, then lets you review and export the results.

  1. 01

    Select a PDF

    Choose up to 50 PDF files (25 MB and 100 pages per file). Text extraction is the default; optional OCR is available only when bundled in the build, for English scans up to 20 pages.

  2. 02

    Extract invoice fields

    The browser reads document text and applies heuristic rules to identify invoice information and line items. Results depend on the document's layout.

  3. 03

    Review and correct

    Inspect the extracted information before export. Confirm flagged numeric dates and correct unusual line-item rows when necessary.

  4. 04

    Export your data

    Export a combined XLSX workbook, invoice-level CSV, line-item CSV, or JSON with validation status.

Conceptual privacy architecture diagram. It does not depict a network capture.

DocuExtract has no application backend, account, database, analytics or telemetry. Invoice data is not written to URLs, localStorage or sessionStorage. PDF buffers are released and documents are destroyed after processing. React rendering does not use dangerouslySetInnerHTML. You can independently inspect the browser's network tab to verify network activity while using the app.

Local processing describes the application's design, not a guarantee about every aspect of your device, browser, extensions or hosting provider. Read the privacy information and review the repository privacy document.

DOCUMENT COMPATIBILITY

Which invoice PDFs are supported?

Text-based PDFs are supported; compatibility depends on the document and how its content is arranged.

Document typeStatusPractical guidance
Text-based PDFSupportedReview all extracted values before export.
Multi-page invoiceSupportedUp to 100 pages.
Scanned or image-only PDFOptional, build-dependentWhen bundled, local English OCR is limited to 20 pages and results always need review. Live assets NOT VERIFIED.
Password-protected PDFLimitedEncrypted files are rejected unless already decrypted.
Corrupt PDFNot supportedUse a valid, readable PDF.
Handwritten invoiceNot guaranteedCheck the result manually; handwritten recognition is not guaranteed.
Multiple invoices in one PDFSupported with limitsSplitting is based on invoice-number changes; boundary edge cases are not fully verified.

Extraction is heuristic. Labels and values need to be on the same line or in neighbouring columns of the same row. A label above its value is not read. Line-item detection uses column gaps and table headers, so unusual tables may need manual correction on the review screen.

For accounting, tax, payment or legal use, review every output and independently verify important fields against the original document. DocuExtract is a data-extraction aid, not a substitute for professional verification.

QUICK ANSWERS

Frequently asked questions

These short answers cover privacy, file support, exports and safe use.

Are my invoice PDFs uploaded?

Application code processes invoice files locally in your browser and does not upload them to an application backend. You can inspect the browser's network tab to verify network activity.

Can DocuExtract read scanned invoices?

OCR is optional and build-dependent. When bundled, local Tesseract supports English only, up to 20 pages per PDF; results are capped at 75% confidence and marked Review. The deployed build's OCR assets are NOT VERIFIED.

Which export formats are available?

DocuExtract exports XLSX, CSV and JSON. CSV can export invoice-level rows or line items; XLSX is a combined workbook and JSON includes validation status.

Can I trust the extracted values without checking them?

No. Extraction is heuristic, and every output must be reviewed before accounting, tax, payment or legal use.

Can one PDF contain several invoices?

A PDF can be split where invoice numbers change; multi-page invoices are kept together. Boundary edge cases are not fully verified, so inspect each split.
